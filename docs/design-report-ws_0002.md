# 四路 INT8 并行计算加速器设计报告

审核版本：MPC Frame 用户设计 `rv32e-pca-5000inst`，ECOS Studio 工作区 `ws_0002`。设计名 `pca`，顶层 `Rv32ePca`，采用组合乘法实现。

## 1 功能概述

PCA（Parallel Computing Accelerator，并行计算加速器）是基于 MPC Frame 模板的四路 8 位并行运算模块，自身不包含 CPU。模块由 Frame 接口封装、APB 风格寄存器接口和计算数据通路组成。

外部控制器写入操作数 A、B、累加初值 ACC 及操作码，置位 START 启动运算，通过 DONE 轮询或 IRQ 电平通知判断完成，再读取 RESULT。IRQ 只通知完成，不直接传输结果。

支持逐字节加法、减法、无符号绝对差，有符号 INT8 四项点积、点积加 ACC、无符号绝对差求和加 ACC，以及 32 位异或、与、或和复制，共 10 类操作。四个 8×8 有符号组合乘法器并行产生乘积，经符号扩展后求和。

## 2 设计指标

| 项目 | 指标 |
|---|---|
| 工艺与语言 | ics55 标准单元工艺库，Verilog RTL |
| 目标时钟 | 50 MHz，20 ns 周期 |
| 数据位宽 | A、B 各 32 位，分别包含四个 8 位数据；ACC、RESULT 为 32 位 |
| 计算延迟 | 接受启动后 1 个计算周期完成，不含接口访问开销 |
| 接口 | Frame 66 位用户载荷，承载 APB 风格数据、地址、控制和状态信号 |
| 状态与通知 | BUSY、DONE、ERROR 和可使能的 IRQ |
| 逻辑规模目标 | 综合映射标准单元不超过 5000 个 |

每次处理一条命令，无 DMA、自主访存或本地 SRAM。加减及累加溢出按结果位宽截断，不提供饱和运算。ACC 由软件写入，结果不会自动回写 ACC。

## 4 回片后测试方法及预期效果

采用 FPGA 控制器与上位机参考程序，按载板电压和引脚定义连接 Frame。FPGA 提供同步时钟及总线激励，读事务开始前释放双向数据线；芯片在读 SETUP 阶段已驱动该总线。PCA 数据通路为同步复位，复位期间须提供有效时钟。

1. **上电与接口**：复位期间稳定驱动分配的设计编号，提供时钟后按 Frame 时序释放复位，等待内部启动完成。验证用 Frame 要求编号在释放复位前至少稳定两个时钟边沿；最终以组织方集成版本为准。低频读 ID、CAPS，预期分别为 `0x50434134`、`0x010A0804`。
2. **基本计算**：覆盖 10 类操作。A=`0x04030201`、B=`0x08070605` 的点积预期为 70；点积累加且 ACC=10 时预期为 80。
3. **边界与随机数据**：覆盖零、正负数、−128/127、截断溢出、字节写使能，与软件参考结果逐位对照，预期无不一致。
4. **控制与通知**：检查启动、结果、DONE/IRQ 置位与清除、连续合法命令及复位恢复。DONE 可由软件清除、新命令或复位清除；IRQ 由使能和 DONE 共同决定。BUSY 仅一拍，正常 APB 读取可能看不到 BUSY=1，不以必须读到忙状态作为验收条件。
5. **频率与连续运行**：低频通过后逐步提高至 50 MHz，执行连续随机任务；预期在规定板级条件下结果正确、接口稳定、PERF=1。内部一拍计算不等于整个软件调用仅需一拍。

以上为回片测试计划及预期，尚无硅上实测结果。
